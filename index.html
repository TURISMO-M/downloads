Installation Guide

Platform-specific steps to verify and launch downloaded binaries.

  1. Download Stock-Manager-1.1-Windows-Setup.exe from the release panel above.
  2. Verify the SHA-256 checksum in PowerShell with Get-FileHash .\Stock-Manager-1.1-Windows-Setup.exe -Algorithm SHA256.
  3. Run the Setup installer to install Stock Manager. If Windows SmartScreen prompts, choose More info and Run anyway.
